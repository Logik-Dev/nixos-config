# Audit du homelab — septembre 2026

Audit complet du dépôt réalisé le **2026-09-24**. Objectif : servir de feuille de
route multi-sessions. Chaque constat a un **ID stable** ; on avance lot par lot en
mettant à jour la colonne `Statut` et le journal de sessions en fin de document.

## Comment utiliser ce document

- IDs : `P0-*` (bugs critiques silencieux), `SEC-*` (sécurité), `MON-*`
  (monitoring/alerting), `BAK-*` (backups/drills), `CLN-*` (code mort/nettoyage),
  `FAC-*` (factorisation), `ADD-*` (ajouts), `DOC-*` (documentation).
- Statuts : `todo` · `en cours` · `fait` · `reporté` · `rejeté`.
- Toute correction doit finir par `nix flake check` + déploiement de l'hôte
  concerné, et être notée dans le journal (§ Journal de sessions).
- Les références `fichier:ligne` correspondent à l'état du dépôt au 2026-09-24
  (commit `0ec0ad2`).

## Méthode & périmètre

Analyse statique des ~140 fichiers `.nix` + croisement avec :

- le **nixpkgs épinglé** (`flake.lock` → `34ab9907…`, nixos-unstable 26.11) ;
- le **code upstream** `alertmanager-ntfy` v1.2.1 (alexbakker) et le test NixOS
  correspondant, pour valider le chemin du webhook ;
- les modules nixpkgs des services utilisés (`seerr`, `n8n`, `immich`, `smartd`,
  `tailscale`, `restic`, `pgbackrest`…) pour vérifier unités systemd, chemins
  `DynamicUser`/`StateDirectory`, options réellement consommées.

Les points marqués **Vérifié** ont été confirmés dans ces sources ; les autres
sont des constats statiques à confirmer au déploiement.
